Install ESP32-C3 Super Mini Jiggler

Install the firmware on your ESP32-C3 Super Mini directly from your browser.

  1. Use a desktop computer with the latest Chrome or Edge.
  2. Connect the C3 with a USB data cable.
  3. Click Install below and choose the ESP32-C3 serial port.
  4. Approve the prompt to install the firmware.
  5. After installation, set the values below and click Save settings.
