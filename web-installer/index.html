Install C3 Mouse Jiggler

Install the firmware on your ESP32-C3 Super Mini directly from your browser.

  1. Use a desktop computer with the latest Chrome or Edge.
  2. Connect the C3 with a USB data cable.
  3. Click Install below and choose the ESP32-C3 serial port.
  4. Approve the prompt to erase and install the firmware.

Installing replaces the firmware and clears saved BLE bonds. Pair BT Mouse again in your computer's Bluetooth settings. If the serial port does not appear, try another USB data cable or hold BOOT while pressing and releasing RESET, then try again.
