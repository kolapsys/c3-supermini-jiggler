Install C3 Mouse Jiggler

Install the firmware on your ESP32-C3 Super Mini directly from your browser.

  1. Use a desktop computer with the latest Chrome or Edge.
  2. Connect the C3 with a USB data cable.
  3. Click Install below and choose the ESP32-C3 serial port.
  4. Approve the prompt to install the firmware.
  5. After installation, set the values below and click Save settings.

Jiggling settings

These values are saved on the C3 and remain after it restarts.

Flash the firmware first, then reconnect to the board here to save settings.

Flashing clears saved settings and BLE bonds. Save your settings above and pair BT Mouse again after installing. If the serial port does not appear, try another USB data cable or hold BOOT while pressing and releasing RESET, then try again.
